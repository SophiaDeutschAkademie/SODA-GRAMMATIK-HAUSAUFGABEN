# SODA GRAMMATIK HAUSAUFGABEN

Sophia Deutsch Akademie의 독일어 문법 과제(Hausaufgabe) 웹앱이에요. Lektion 01~16 과제를 한 곳에서 풀고, 목차 상단에서 나의 과제 진행률을 확인할 수 있어요.

## 구조

- `index.html` : 표지와 목차(진행률)
- `lektionen/` : Lektion 01~16 과제 페이지
- `assets/` : 글꼴, 오디오, 스크립트, 로고

## 배포 (GitHub Pages)

Settings → Pages → Branch를 `main`, 폴더를 `/ (root)`로 선택하면 돼요.
